# Security Policy

## Supported Versions

This project is maintained on a best-effort basis. Security fixes are typically applied to `main`.

## Reporting a Vulnerability

Please do not open public issues for potential vulnerabilities.

Report privately using GitHub Private Vulnerability Reporting (Security tab), and include:
- a clear description of the issue
- reproduction steps or proof-of-concept
- affected version/commit
- potential impact

I will acknowledge receipt and aim to provide an initial response within 5 business days.

## Scope Notes

- This repo intentionally excludes production secrets and environment-specific credentials.
- If you discover exposed credentials, treat it as sensitive and report privately.
